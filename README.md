# Modern Rotary Screensaver

A beautiful, aesthetic, and fully customizable desktop clock screensaver built with PyQt6.
Features both a Fliqlo-style flip clock and a Modern Pixel Rotary style dial.

## Features
- **Two Distinct Styles**: Switch between classic flip clock and modern rotary dual ring.
- **Ambient Glowing Orbs**: A dynamic, slowly shifting ambient background (can be toggled).
- **Modern Rotary Tracks**: Continuous grey dial tracks behind minute/second ticks for better visual structure.
- **Date Engine**: Smooth date and time tracking.

## Requirements
- Python 3.x
- PyQt6

## Installation

1. Install PyQt6:
```cmd
pip install PyQt6
```

2. Run the application:
```cmd
python screensaver.py
```
Alternatively, double-click `run.vbs` on Windows to launch it silently without a console window.

## Controls
- **Up/Down Arrow**: Switch between Flip Clock and Modern Rotary styles.
- **Plus/Minus (+/-)**: Scale the clock size (Flip Clock mode only).
- **Space / Windows Key**: Toggle ambient background orbs.
- **Mouse Movement / Click / Any Key**: Exit the screensaver.
